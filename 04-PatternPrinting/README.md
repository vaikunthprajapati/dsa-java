# 04 - Pattern Printing

This folder contains Java pattern printing problems implemented using both iterative and recursive approaches.

Pattern problems helped me understand loops, nested loops, recursion, coordinate logic, and problem decomposition.

## Sections

### Recursive Patterns

Patterns created using recursion.

Topics include:

- Recursive Stars
- Recursive Triangles
- Recursive Pyramids
- Recursive Hollow Patterns
- Recursive Number Patterns

### Loop Based Patterns

Patterns created using loops.

Topics include:

- Square Patterns
- Rectangle Patterns
- Triangle Patterns
- Pyramid Patterns
- Inverted Pyramid Patterns
- Diamond Patterns
- Hollow Patterns
- Number Patterns
- Character Patterns

## Concepts Practiced

- Nested Loops
- Recursion
- Row-Column Logic
- Space Management
- Pattern Visualization
- Problem Decomposition

## Learning Outcomes

After completing this section, I learned:

- How nested loops work internally
- Recursive thinking
- Visual problem solving
- Coordinate-based logic
- Pattern recognition skills useful in DSA
