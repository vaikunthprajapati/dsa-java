# 02 - Loops

This folder contains Java programs and practice problems based on looping concepts.

The goal of this section is to build a strong understanding of iteration, repetition, nested loops, and problem solving using loops.

## Topics Covered

### For Loop
- Basic iteration
- Counting problems
- Range-based operations

### While Loop
- Condition-driven iteration
- Input-based problems

### Do-While Loop
- At least one execution behavior
- Menu-driven programs

### Nested Loops
- Multi-level iteration
- Pattern generation
- Mathematical problems

## Problems Included

- Even Numbers
- Factors of a Number
- Factorial
- Sum Problems
- Loop Practice Questions
- Nested Loop Problems

## Learning Outcomes

After completing this section, I should be able to:

- Use all loop types confidently
- Solve mathematical problems using loops
- Understand nested iteration
- Build a foundation for pattern printing
- Prepare for recursion and DSA problem solving
